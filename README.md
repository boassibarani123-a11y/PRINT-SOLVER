## 📖 Tentang Print Solver

**Print Solver** adalah aplikasi web layanan percetakan online yang dirancang untuk memudahkan pengguna dalam mengelola kebutuhan cetak dokumen. Platform ini menyediakan fitur unggah dokumen secara mandiri, kalkulasi jumlah halaman, estimasi harga otomatis, manajemen pesanan, hingga kemudahan transaksi yang efisien.

## ✨ Fitur Utama

- 📁 **Unggah Dokumen Mudah:** Mendukung berbagai format file dokumen untuk dicetak.
- 🧮 **Kalkulasi Otomatis:** Menghitung jumlah halaman dan total harga secara presisi dan instan.
- 💰 **Manajemen Harga & Transaksi:** Pengaturan tarif cetak fleksibel dan sistem pencatatan pesanan yang terstruktur.
- 📊 **Dashboard Kelola Pesanan:** Membantu penyedia jasa dan pengguna memantau status pesanan dengan transparan.

## 🛠️ Tech Stack

Proyek ini dibangun menggunakan teknologi modern:
* **Backend:** PHP, Laravel
* **Frontend:** Blade, HTML, CSS, JavaScript / Tailwind CSS
* **Database:** MySQL
* **Build Tool:** Vite
